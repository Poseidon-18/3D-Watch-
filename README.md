I love watching movies, and one recurring issue on everyday booking sites like BookMyShow is that you never quite know how the screen will look from your selected seat until you're actually inside the hall. To solve this, I built **3D-Watch** 

This is a 3D model where you can select your seat and preview the exact perspective and view of the screen from that specific angle. Please note that this is a **basic prototype and an active work in progress (WIP)**!


##  Tech Stack

* **3D Graphics / Rendering:** [Three.js](https://threejs.org/)
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Version Control:** Git & GitHub
